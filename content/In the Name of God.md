شما کاملاً حق دارید. ابداع دوباره چرخ برای اتصال آبسیدین به وبلاگ منطقی نیست و جامعه کاربری متن‌باز مدت‌هاست که این مسیر را به بلوغ رسانده است.

در حال حاضر، استاندارد طلایی و بی‌رقیب برای تبدیل مستقیم یادداشت‌های آبسیدین به یک وب‌سایت علمی، پروژه‌ای به نام **Quartz** (کوارتز) است. این ابزار دقیقاً برای منطق آبسیدین ساخته شده است و فایل‌های شما را بدون نیاز به هیچ اسکریپت واسط یا تغییر دستی، به یک وبلاگ مدرن تبدیل می‌کند.

**چرا Quartz بهترین گزینه است؟**

* **پشتیبانی ذاتی از سینتکس آبسیدین:** لینک‌های داخلی (`[[لینک]]`)، تگ‌ها و تصاویر دقیقاً مانند داخل نرم‌افزار کار می‌کنند.
* **ریاضیات فوق‌سریع:** به جای MathJax، از موتور KaTeX استفاده می‌کند که فرمول‌های درون‌خطی `$x$` و بلوک‌های `$$x$$` را به صورت آنی و با استایل بسیار زیبا رندر می‌کند.
* **گراف ارتباطات:** یک نمای گراف (Graph View) تعاملی شبیه به خود آبسیدین در کنار صفحات می‌سازد که ارتباط بین نوت‌های شما را نشان می‌دهد.
* **بک‌لینک‌ها:** در انتهای هر یادداشت، نشان می‌دهد که کدام یادداشت‌های دیگر به این مطلب ارجاع داده‌اند.

در ادامه، داکیومنت گام‌به‌گام و استاندارد برای راه‌اندازی این سیستم را بررسی می‌کنیم.

### گام ۱: پیش‌نیازها و راه‌اندازی اولیه

کوارتز بر پایه Node.js کار می‌کند. ابتدا مطمئن شوید **Node.js** و **Git** روی سیستم شما نصب هستند.
ترمینال را باز کرده و مخزن تمپلیت کوارتز را دریافت کنید:

```bash
git clone https://github.com/jackyzha0/quartz.git my-blog
cd my-blog
npm install
npx quartz create

```

*(هنگام اجرای دستور آخر، از شما چند سوال ساده برای پیکربندی اولیه پرسیده می‌شود که می‌توانید با فشردن `Enter` مقادیر پیش‌فرض را تایید کنید).*

### گام ۲: اتصال به مخزن گیت‌هاب شما

باید این پوشه جدید را به ریپازیتوری وبلاگ خودتان متصل کنید. در همان ترمینال دستورات زیر را وارد کنید:

```bash
git remote remove origin
git remote add origin https://github.com/MeysamIzadi/meysamizadi.github.io.git

```

### گام ۳: مدیریت نوت‌ها و ادغام با آبسیدین

درون پوشه اصلی کوارتز، یک فولدر به نام `content` وجود دارد. **این پوشه، قلب تپنده وبلاگ شماست.**
تنها کاری که باید بکنید این است که فایل‌های Markdown و تصاویر خود را درون این پوشه قرار دهید. راحت‌ترین جریان کاری (Workflow) این است که مستقیماً در نرم‌افزار آبسیدین، روی گزینه `Open another vault` کلیک کنید و پوشه `content` کوارتز را به عنوان یک ولت جدید باز کنید. هر چیزی که اینجا بنویسید، مستقیماً آماده انتقال به سایت است.

### گام ۴: پیکربندی زبان فارسی و فرمول‌های ریاضی

فایل `quartz.config.ts` را با یک ادیتور باز کنید. در بخش تنظیمات، ویژگی `locale` را به `'fa-IR'` تغییر دهید تا تاریخ‌ها و ساختار کلی برای زبان ما بهینه‌سازی شود.

سپس برای اضافه کردن فونت وزیرمتن و تنظیم هوشمند چینش راست‌به‌چپ (به طوری که فرمول‌ها و کدهای انگلیسی به هم نریزند)، فایل `quartz/styles/custom.scss` را باز کرده و کدهای زیر را در آن قرار دهید:

```scss
@import url('https://cdn.jsdelivr.net/gh/rastikerdar/vazirmatn@v33.003/Vazirmatn-font-face.css');

body {
  font-family: 'Vazirmatn', -apple-system, BlinkMacSystemFont, "Segoe UI", Helvetica, Arial, sans-serif;
}

/* تنظیمات هوشمند Bidi برای خطوط ترکیبی فارسی و انگلیسی */
article, p, h1, h2, h3, h4, h5, h6, li {
  unicode-bidi: plaintext;
  text-align: start;
}

/* محافظت کامل از ساختار چپ‌به‌راست فرمول‌های ریاضی و بلوک‌های کد */
.math, .math-display, pre, code {
  direction: ltr !important;
  text-align: left !important;
  unicode-bidi: isolate;
}

```

### گام ۵: انتشار خودکار با یک دستور

دیگر نیازی به درگیری با دستورات طولانی `git add` و `git commit` نیست. کوارتز یک ابزار همگام‌ساز داخلی دارد. هر زمان که نوشتن یادداشت در آبسیدین تمام شد، ترمینال را باز کنید و بنویسید:

```bash
npx quartz sync

```

این دستور فایل‌های شما را بیلد کرده و به گیت‌هاب می‌فرستد.

### گام نهایی: تنظیمات سرور گیت‌هاب

کوارتز از GitHub Actions برای ساخت سایت استفاده می‌کند. بنابراین فقط برای بار اول باید این تنظیم را در سایت گیت‌هاب انجام دهید:
۱. وارد ریپازیتوری `meysamizadi.github.io` در سایت گیت‌هاب شوید.
۲. به تب **Settings** بروید و از منوی سمت چپ روی **Pages** کلیک کنید.
۳. در بخش **Build and deployment**، منوی کشویی **Source** را پیدا کنید و آن را از حالت `Deploy from a branch` به **GitHub Actions** تغییر دهید.

از این لحظه به بعد، هر بار که دستور `npx quartz sync` را می‌زنید، سایت شما با تمام گراف‌ها، فرمول‌ها و لینک‌های آبسیدین به صورت بی‌نقص آپدیت خواهد شد.
